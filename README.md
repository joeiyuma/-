# NISA × 変額保険 併用提案スライド

NISAを肯定しながら、変額保険を「出口戦略」と「万が一への備え」で補完する営業資料です。横向き画像として利用できる 16:9 SVG スライドを `slides/` に10枚生成しています。

## 収録スライド

1. NISAを最大限活かし、変額保険で“守り”を足す
2. 長期投資：時間を味方にする
3. 資産分散：たまごを1つのかごに盛らない
4. 時間分散：りんごを毎月少しずつ買う
5. NISAはまず肯定：非課税で資産形成の主役に
6. 比較：NISAと変額保険は“競合”ではなく“役割分担”
7. 出口戦略：子ども18歳の時に暴落したら？
8. スイッチングによる暴落対策：使う数年前から守りへ
9. 万が一への備え：運用にも“団信的発想”を
10. 提案結論：NISAだけでなく、変額保険も持つ理由

## 営業設計のポイント

- NISAは「非課税で増やす主役」として肯定し、否定しない構成です。
- 変額保険は「出口前のスイッチング」「死亡保障」「払込免除」によって、NISAだけでは埋めにくい不安を補完する位置づけにしています。
- 教育資金のように使う時期が決まった資金は、暴落時に売却せざるを得ないリスクを示し、事前スイッチングの必要性につなげます。
- 住宅ローンの団体信用生命保険を例に、資産形成にも払込免除という“団信的発想”を加える提案導線にしています。

## 注意事項

本資料は一般的な情報提供であり、特定の金融商品・保険商品の勧誘資料ではありません。NISAも変額保険も元本保証ではなく、変額保険は市場リスク、保険関係費用、運用関係費用、解約控除等により損失が生じる場合があります。実際の提案時は、各商品の契約概要・注意喚起情報・約款・手数料・税務上の取扱いを必ず確認してください。
