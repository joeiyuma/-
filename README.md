# クリボー風コピペ帳

iPhone / iPad のSafariで使いやすい、1タップコピー用の静的Webアプリです。
よく使う返信文やSNS文、個人メモを保存して、必要なときにすぐコピーできます。

## 使い方

1. `index.html` をブラウザで開きます。
2. コピペしたいカードの「コピー」を押します。
3. 新しい定型文は右側（iPhoneでは下側）のフォームから追加できます。
4. iPhone / iPad ではSafariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリ風に起動できます。

## 機能

- クリボー風のマスコット付きUI
- iPhone向けの縦長レイアウト
- iPad向けの2カラムレイアウト
- カテゴリチップと検索
- Clipboard APIによる1タップコピー
- `localStorage` による端末内保存
